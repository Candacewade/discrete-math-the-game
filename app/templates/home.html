What is this?

Discrete Math: The Game is a tiny interactive web app that helps you build intuition for core topics in discrete math using visual animations and quick practice questions.

Purpose

The goal of math isn’t solely memorizing formulas but seeing why the formulas work, so you can recognize which principle to use in new problems! The purpose of this game is to show you that why visually.

Levels

  • Level 1: Product Principle — “AND” choices multiply (visualized as branching possibilities).
  • Level 2: Powersets — each element is in or out → 2^n subsets.
  • Level 3: Combinations — choose k elements from n total elements: C(n,k).

How to win

Each level is completed by getting a 3-in-a-row streak of correct answers. Finish all three levels to win the game!
